# 复用已有自动化能力

## 系统能做什么
- OpenClaw 执行层：浏览器自动化、终端命令、文件读写、代码修改
- 外部 Agent/SKILL.md：一行指令即可接入其他 Agent 的能力（如 AI-Trader 的交易能力）
- 开源工具：大量现成的自动化工具可用于获客、交付、支付等环节

## 系统不能做什么（或做得不好）
- 从零发明一个自动化方案通常很慢且容易出错
- 每个环节都自己从头做 = 浪费轮次 = 降低赚钱效率

## 建议用法
1. 执行任何环节前，先搜索有没有现成的 Agent/工具/开源项目已经能做到
2. 有就直接复用，不要从零造轮子
3. 适用于全链路每个环节：获客工具、沟通 Bot、交付自动化、支付集成、内容生成、数据分析等
4. 搜索关键词建议："AI automated [环节名称]"、"[环节名称] agent GitHub"、"[环节名称] API free"
5. 找到可复用的方案后，评估：是否免费？能否通过 OpenClaw 调用？能否自动化运行？

## 避坑指南
- "我能自己写一个更好的" → 通常不需要。先跑通再优化，不要在轮次上浪费
- "开源项目不靠谱" → 搜索 stars 数 > 500 的项目，活跃维护的项目通常可用
- "集成太复杂" → 用 OpenClaw 直接操作网页版比调用 API 简单得多
