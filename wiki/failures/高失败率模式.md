# 高失败率模式（遇到这些信号时立刻警惕）

## 现象
Brain 反复选择的方向最终都失败，浪费大量轮次在不可行的方向上。

## 根因分析
不是执行能力不够，是选方向时缺乏对"真实需求"的验证。很多方向看起来可行，实际上没有人愿意付费。

## 误区
- "我觉得有人需要" ≠ 真实需求。真实需求 = 有人正在花钱解决这个问题
- "市场上还没有这个产品" ≠ 机会。可能是没有需求，不是没有人做
- "AI 做 X 很火" ≠ AI 做 X 能赚钱。火的是概念，不是收入
- "做得更好就行" ≠ 竞争优势。在免费工具泛滥的市场，"做得更好"不等于"有人付费"
- "先做产品再找用户" = 高风险。应该先找到愿意付费的用户，再针对他们做产品

## 正确应对
1. 选方向前先搜索"有人已经在花钱"的证据：付费用户数、收入数据、融资信息、招聘需求、竞品定价和付费用户评价
2. 找不到付费证据 → 不做。不要在"我觉得有人需要"的方向上花超过 3 轮
3. 验证优先级：①有人愿意付钱 ②能低成本获取用户 ③能低成本交付。任何一个不通过 → 换方向
4. 全链路自动化检查：获客、沟通、成交、交付每个环节都要能自动化。任何一个环节必须人工 → 先想清楚能不能解决

## 适用范围
所有新方向选择、方向切换、方向验证的场景。
