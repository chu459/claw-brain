# Claw-brain 自主决策新项目模板

结论：凡是 Codex 里新建、且和 Claw-brain 自主决策有关的项目，都按这个模板开局。

## 项目目标

把一个模糊目标，变成可执行、可验证、可复盘的自动化闭环。

不要只做分析。

必须推进到真实动作。

## 默认目录

```text
project/
  AGENTS.md              # 项目执行规则
  goal.md                # 当前目标和最低验证量
  plan.md                # 阶段计划
  decisions.md           # 每轮关键决策
  validation.md          # 真实数据记录
  outputs/               # 产物
  logs/                  # 运行日志
```

## 开局必须写清

1. 目标是什么。
2. 成功怎么算。
3. 最低验证量是多少。
4. 哪些事需要问用户。
5. 第一件能立刻执行的事是什么。

## 商业类项目默认验证量

| 场景 | 最低验证量 |
| --- | --- |
| 闲鱼卖服务 | 500 次曝光，或 10 次咨询 |
| 邮件获客 | 50 个客户触达 |
| 小红书内容 | 3 条笔记，至少看点击、收藏、评论 |
| 抖音内容 | 3 条视频，至少看完播、互动、涨粉 |
| SaaS 小工具 | 20 个目标用户触达，或 5 个真实试用 |
| 接广告/API 项目 | 20 个候选客户，或 5 个真实询价 |

没跑够最低验证量，不要太早放弃。

跑够后，如果没有真实动作数据，再换方向。

## 每轮决策记录格式

```md
## Round 1

- 目标：
- 观察：
- 决策：
- 执行动作：
- 结果：
- 下一步：
- 需要记住：
```

## 需要问用户的动作

- 登录。
- 扫码。
- 验证码。
- 花钱。
- 发布内容。
- 删除或覆盖重要文件。
- 改线上系统。

## 不需要问用户的动作

- 读文件。
- 搜索资料。
- 写草稿。
- 本地新增文件。
- 生成方案。
- 跑测试。
- 做非破坏性分析。

## 完成标准

项目不是“写完文档”就完成。

至少要有：

- 一个明确目标。
- 一个阶段计划。
- 一次真实执行。
- 一条真实数据记录。
- 一个下一步判断。
